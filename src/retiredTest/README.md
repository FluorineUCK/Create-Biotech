# 已退出的旧生产验收

这里保留的是 C65 切断物理 Computer 生产宿主之前的测试源码，包括当时未提交的修改。它们不进入游戏包、默认测试集或首版验收计数。旧测试要求放置普通 Computer 后自然形成生产 Epoch、启用旧面板或启动旧 worker；现在这些动作恰好是不能再发生的行为。

混合测试类保留了切换前的完整副本；居民安装与拆除守恒、书库、玩家菜单、外壳等仍适用的部分继续在 `src/test/java` 编译。新实现用真实注册的 Computer 验证旧 V5 原样重存、实体居民仍可移出、程序和本机内存仍能恢复。历史文件不能作为恢复生产运行接口的理由。

原工厂面板菜单及封包的旧测试保存在 `factory-panel/`，不参与构建。仍有效的权限、物料端口及真实打包行为由当前注册的菜单和原生 GameTest 检查。
